# Repository collaboration instructions

This is a learning repository. Respect the user's rule: do not create exercise solutions before attempts.

- Do not implement Challenge.cs, harder exercises or the capstone on behalf of the learner unless they later explicitly request a solution after an attempt.
- Help through contract clarification, hints, tests and review first.
- Preserve learner attempts and supplied acceptance assertions.
- Do not skip/weaken tests or declare progress complete without evidence.
- Runnable adjacent examples are allowed; avoid directly solving the assigned challenge.
- Use .NET 10 / C# 14 stable defaults and the existing central package/version configuration.
- Add relevant Day traits to tests and document any new project/test commands.
- Build every project and run the affected tests; initial unsolved challenge failures are intentional.
- Edit day files in place; never regenerate over learner attempts.
